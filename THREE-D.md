# Moonlit terrace

The homepage progressively enhances the existing illustrated hero with a real-time
Three.js scene. `assets/js/terrace.js` builds the architecture, lighting, furniture,
framed memories, and writing table. `assets/css/terrace.css` styles its HTML controls.

Four buttons select camera positions. OrbitControls provides unrestricted
horizontal orbit, vertical orbit, wheel/pinch zoom, and right-drag/two-finger
pan. The focusable canvas also supports arrow-key pan, +/- zoom, and R to reset.
Preset buttons restore a familiar view after exploring; scrolling outside the
canvas continues through the page. Camera rendering still runs only on demand.
The terrace chapter links open Our stories, Reasons, Surprises, Letters, and
For you. The framed photos, hanging stars, gift boxes, envelope, and floral
paper also navigate to their corresponding HTML sections when selected.
The writing-table view opens the existing final-letter dialog and uses the same
personal content in `assets/js/config.js`. The gallery currently uses the existing
scenic sample images. The rest of the site's memories, gifts, and letters remain
in HTML below the scene.

Three.js 0.170.0 is served locally from `assets/vendor/three`, with its MIT license.
There is no build step or runtime CDN requirement. Serve the repository with
`python3 -m http.server 8000`; ES modules require HTTP rather than file URLs.

Rendering runs on demand during camera changes and pauses when offscreen or the
document is hidden. Pixel density is capped at 1.6. Reduced-motion preferences
make view changes immediate. Without WebGL, or after context loss, the existing
illustrated hero and all normal website controls remain usable.

The environment is a modeled terrace, not a photogrammetric reconstruction
of the reference villa. It uses procedural wood grain, fabric and stone bump
maps, directional and spot shadows, and existing site artwork. The floral paper
uses the same `letter-card.webp` as the final chapter, with personal text drawn
from `LOVE_SITE_DATA`.

The furnishings use beveled edges, woven upholstery with cushion piping, a
fringed rug, wrapping-paper texture, a lacquer-and-brass pen, gallery wainscoting,
and pergola braces and fittings. A shaded ceramic-and-brass table lamp lights
the writing desk. Candle lanterns hang from roof chains instead of sitting on
the floor. These details are built in Three.js alongside the Blender props.

`assets/js/terrace-garden.js` adds a seeded garden around every side: textured
terrain, stone steps and a winding path, rocks, lavender, branching trees with
bark, and individual grass blades. Grass, leaves and flowers use instancing to
keep draw calls bounded. Canvas-generated textures are original project work.

## Blender assets

`tools/blender/build_terrace_props.py` authors the fern and lantern in Blender
4.3.2. Rebuild from the repository root with:

```sh
blender -b -t 2 --python tools/blender/build_terrace_props.py
```

Editable compressed `.blend` sources are in `tools/blender/`; the browser loads
only the GLBs from `assets/models/`. Meshes are joined by material to reduce draw
calls. The fern has 80,160 triangles / 9 material primitives; the lantern has
4,532 triangles / 5 primitives. Three fern placements and two hanging lanterns
share their respective model's GPU resources.
The assets are original project work generated by the checked-in script, with
no third-party model downloads. Three.js and its loaders retain their MIT license.
Static GLB headers and geometry counts, actual browser imports, desktop/mobile
navigation, dialog actions, and screenshots were checked during implementation.
